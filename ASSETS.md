# Artwork, models and audio

Source models and terrain textures are provided to work on Hearthvale. They are
not covered by any code license unless explicitly stated. This repository does
not grant permission to reuse its artwork, branding or audio in another game.

Existing models include owner-supplied AI-generated assets and Blender-authored
Hearthvale buildings and props. A complete per-file provenance register is still
needed. Do not assume an external sound, texture or model is redistributable
because it can be downloaded. Include the creator, source, license and any
required attribution when proposing a new asset.

The OSRS cache extracts and imported Varrock account draft are not included in
this repository. RuneScape is a visual reference for original Hearthvale assets;
this is not a grant to redistribute Jagex content.
